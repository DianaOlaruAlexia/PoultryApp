Poultry Health Checker
A simple browser-based poultry health checker built with HTML, CSS, and vanilla JavaScript.
The application lets the user:
Select a poultry type.
Choose symptoms using drag-and-drop.
Remove selected symptoms.
Submit the selection and view a list of possible illnesses.
See an educational-use warning recommending consultation with a veterinarian.

Project Structure

PoultryApp-main/
├── index.html
├── script.js
├── styles.css
└── README.md


`index.html`
Defines the application interface:
Poultry type selector.
Available symptoms list.
Drag-and-drop area for selected symptoms.
Submit button.
Area for displaying results.
Veterinary/educational disclaimer.

`script.js`
Contains the application logic:
Defines the available symptoms.
Creates draggable symptom elements.
Handles drag-and-drop selection.
Allows selected symptoms to be removed.
Validates that a poultry type and at least one symptom are selected.
Simulates an API request with `mockApiCall()`.
Displays possible illnesses returned by the mock response.
> **Note:** The current implementation uses a mock API response. It does not perform a real medical/veterinary diagnosis or call an external backend.

`styles.css`
Contains the visual styling for the application, including:
Layout and spacing.
Form controls.
Symptom panels.
Selected symptom styling.
Submit button.
Warning/disclaimer box.
Symptom color classes.


How to Run
This is a static web application, so no Node.js, database, or backend server is required for the current version.

Option 1 — Open directly
Download or extract the project.
Open the project folder.
Double-click `index.html`.
The application should open in your default web browser.

Option 2 — Run with VS Code
For development, using a local web server is recommended.
Open the project folder in Visual Studio Code.
Install the Live Server extension if necessary.
Right-click `index.html`.
Select Open with Live Server.
The application will open at a local address such as `http://127.0.0.1:5500/`.

Option 3 — GitHub Pages
The project can also be hosted as a static website using GitHub Pages:
Push the project to a GitHub repository.
Open the repository's Settings → Pages.
Configure GitHub Pages to deploy from the desired branch/folder.
Open the generated GitHub Pages URL.


Current Behavior
The application currently returns the same example illnesses for any valid poultry type/symptom combination:

Newcastle Disease
Infectious Bronchitis
The response is intentionally simulated in `mockApiCall()`.
